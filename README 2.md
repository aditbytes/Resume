## Terminal Commands

- Profile: `who`
- Skills: `skills`
- Projects: `projects`
- Contact: `github`, `linkedin`, `email`
- Utilities: `calculator`, `qr-generator`, `password-generator`, `github-feed`
- Games: `snake`, `tetris`, `2048`, `flappybird`, `gameoflife`

## Local Setup

```bash
npm install
npm start
```

Production build:

```bash
npm run build
```

## Personalization

Main files for your personal content:
- `src/data/profile.json` - identity, bio, skills, education, links
- `src/data/projects.json` - project cards and links
- `public/index.html` - SEO/title/meta tags
- `scripts/update-metadata.js` - generated `llms/profile/sitemap` files
